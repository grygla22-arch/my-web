# 창가의 오후 — 베이커리 카페 홈페이지

퇴근길에 들러 할 일을 마무리하는, 따뜻하고 조용한 베이커리 카페 **창가의 오후**의 홈페이지입니다.
이 문서는 사이트를 이어받아 관리할 분을 위한 안내서입니다.

> ⚠️ 가게 이름, 주소, 전화번호, 이메일, 인스타그램 계정, 일부 메뉴와 가격은 **지어낸 값**입니다.
> 실제 운영 전에 반드시 진짜 정보로 바꿔 주세요. 어떤 항목이 지어낸 것인지는 `SHOP.md`에 **[지어냄]**으로 표시돼 있습니다.

---

## 바로 열어보기

빌드나 설치가 필요 없는 순수 HTML/CSS/JS 사이트입니다.

- **내 컴퓨터에서:** `index.html`을 더블클릭해 브라우저로 엽니다.
- **인터넷 주소로:** GitHub 저장소의 Settings → Pages에서 `main` 브랜치를 선택하면
  `https://<계정이름>.github.io/my-web/` 주소로 공개됩니다.

글꼴은 Google Fonts에서 불러오므로, 인터넷이 끊긴 상태에서는 기본 글꼴로 보입니다.

## 자주 하는 수정

### 메뉴 이름·가격 바꾸기
`menu.html`에서 해당 메뉴 이름을 검색해 글자를 고칩니다.
추천 조합 가격처럼 **여러 메뉴 가격이 합쳐진 값**도 함께 확인해 주세요.
바꾼 내용은 `SHOP.md`에도 반영해 두면 다음 사람이 헷갈리지 않습니다.

### 사진 바꾸기
`images/` 폴더에 **같은 파일 이름**으로 덮어쓰면 코드를 고치지 않아도 됩니다.
새 이름으로 넣는다면 HTML의 `<img src="images/...">` 경로도 바꿔 주세요.

### 영업시간·주소·연락처 바꾸기
`index.html` 아래쪽의 영업시간·연락처 부분을 고칩니다.
가게 이름처럼 모든 페이지에 들어가는 정보는 세 HTML 파일의 맨 아래(푸터)도 함께 확인해 주세요.

### 색 바꾸기
`style.css` 맨 위 `:root { ... }`에 색이 이름표(`--cream`, `--brown`, `--olive` 등)로 모여 있습니다.
여기만 바꾸면 사이트 전체에 적용됩니다.
바로 아래 `:root[data-theme="dark"] { ... }`는 **다크 모드용 색**이니 함께 맞춰 주세요.

## 꼭 알아야 할 점

### 소식받기 폼은 아직 실제로 저장되지 않습니다
`subscribe.html`의 폼은 입력값을 확인하고 감사 인사를 보여줄 뿐,
**이름과 이메일을 어디에도 보내거나 저장하지 않습니다.**
실제로 구독자를 모으려면 다음 중 하나를 연결해야 합니다.

- Google Forms, Tally 같은 외부 폼 서비스
- Formspree 같은 폼 전송 서비스 (`<form action="...">`에 주소 지정)
- 스티비, 메일침프 같은 뉴스레터 서비스의 구독 폼

개인정보를 받게 되므로 수집·이용 동의 문구도 실제 운영 방식에 맞게 다시 확인해 주세요.

## 변경 이력 관리

이 폴더는 Git으로 관리되고 GitHub(`my-web` 저장소)에 올라가 있습니다.
수정한 뒤에는 무엇을 왜 바꿨는지 적어서 저장(커밋)하고 GitHub에 올려(푸시) 주세요.

```bash
git add .
git commit -m "메뉴: 라떼 가격 5,000원 → 5,500원 (원두 가격 인상)"
git push
```
